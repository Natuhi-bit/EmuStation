# 実機テスト仕様書

EmuStation（Windows 版・Android 版）と同期サーバーを、実機で確かめるための仕様書です。
背景と環境は [`handover.md`](handover.md) を参照してください。

- **対象の版**：ブランチ `claude/intelligent-johnson-veyi5w` のコミット `729cbae` 以降
  - Windows：GitHub Actions「Windows app」の成果物 `EmuStation-setup`（EmuStation-setup-1.0.0.exe）
  - Android：`app-debug.apk`
  - サーバー：同じコミットの `server/`
- **結果の書き方**：各項目の「結果」に ✅（期待どおり）／❌（違う）／⏭（やらなかった）を書く。❌ は「メモ」に、起きたこと・画面・ログの場所を書く。
- **優先度**：**A**＝今回の変更の確認（必ず）、**B**＝以前からの機能が壊れていないか（できれば）、**C**＝余裕があれば。

|---|---|---|

| P-2 | Windows の PC に、最新のインストーラーで EmuStation を上書きインストールする | |

## 6. リモートプレイ（Sunshine＋Moonlight）

| ID | 優先 | 手順 | 期待する結果 | 結果 | メモ |
|---|---|---|---|---|---|
| R-1 | A | 設定→リモートプレイで、Sunshine のユーザー名・パスワードを入れて「登録する」 | 「登録しました」と出る。Sunshine の設定画面の Applications に EmuStation（ポスター画像付き） | | |
| R-2 | A | `C:\Program Files\Sunshine\config\apps.json` の EmuStation を見る | `cmd` が空、`detached` に `"…\EmuStation.exe" --remote`、`prep-cmd` の `undo` に `"…\EmuStation.exe" --remote-end`、`image-path` がある | | |
| R-3 | A | もう一度「登録する」を押す | 「登録を新しくしました」。EmuStation が 2 つに増えない | | |
| R-4 | A | 間違ったパスワードで「登録する」 | 「ユーザー名かパスワードが違います」 | | |
| R-5 | C | Sunshine を止めて「登録する」 | 「Sunshine が動いていません」 | | |
| R-6 | A | 家の中で、Android の Moonlight と PC をペアリングする | PIN を Sunshine に入れるとペアリングできる。アプリ一覧に EmuStation（ポスター） | | |
| R-7 | A | EmuStation が**起動している**状態で、Moonlight から EmuStation を開く | 起動中の EmuStation が**全画面で前に**出て、Moonlight に映る | | |
| R-8 | A | R-7 のまま、Moonlight のコントローラー（またはスマホにつないだコントローラー）で操作 | **XMB が動く**。決定でゲームを開ける | | |
| R-9 | A | EmuStation が**起動していない**状態で、Moonlight から EmuStation を開く | EmuStation が起動して、全画面で映る。コントローラーで操作できる | | |
| R-10 | A | リモートでゲームを遊び、Alt+F4（Moonlight のキーボード）か「エミュを終了」で終える | セーブがクラウドに送られ、EmuStation が前に戻る。コントローラーでそのまま操作できる | | |
| R-11 | A | Moonlight で「アプリを終了」（Quit） | PC の EmuStation が**全画面を解いて最小化**される。EmuStation は終了せずトレイに残る | | |
| R-12 | B | R-11 のあと、もう一度 Moonlight から EmuStation を開く | また全画面で映る | | |
| R-13 | B | Moonlight を「アプリを終了」せずに閉じ（切断）、もう一度開く | 前の続き（全画面の EmuStation）にそのまま戻れる（このときは最小化されないのが正しい） | | |
| R-14 | A | 外出先（モバイル回線）で、Android の WireGuard をつなぎ、Moonlight の「＋」に PC の自宅の IP アドレスを入れる | PC につながり、EmuStation で遊べる | | |
| R-15 | B | R-14 で映像が乱れたら、Moonlight のビットレートを 10〜20 Mbps に下げる | 乱れが減る | | |
| R-16 | B | 外出先で WireGuard をつないだまま、Android 版で同期する | サーバー（`https://192.168.50.49/emusync`）に同じアドレスでつながる | | |
| R-17 | C | リモートプレイ中でないときに、PC の前で別のゲーム（Steam など）をコントローラーで遊ぶ | EmuStation が勝手に前に出てこない | | |

> R-8 でコントローラーが効かないときは、エミュ（PCSX2 など）では効くかも見る。エミュでも効かないなら、Sunshine の仮想コントローラー（ViGEmBus）が入っていない可能性が高い。
> EmuStation だけ効かないなら、EmuStation の窓が前に出ているか（タスクバーで選ばれているか）をメモする。
